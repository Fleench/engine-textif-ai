\doxysubsection{Detailed Description}
\hypertarget{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md27}{}\doxysubsection{\texorpdfstring{Engine Core (\`{}engine/\+\`{})}{Engine Core (\`{}engine/\+\`{})}}\label{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md27}
This directory houses the foundational framework for the interactive fiction engine. It strictly contains {\bfseries{game-\/agnostic}} framework code and the I/\+O layer. {\bfseries{No demo content or specific game narrative resides here.}}\hypertarget{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md28}{}\doxysubsection{\texorpdfstring{Purpose}{Purpose}}\label{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md28}
The engine\textquotesingle{}s responsibility is to provide the systems, scaffolding, and interfaces upon which any text adventure can be built with exact truth and reliable behavior. Its features include:\+\hypertarget{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md29}{}\doxysubsubsection{\texorpdfstring{Advanced Parsing \& Disambiguation}{Advanced Parsing \& Disambiguation}}\label{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md29}

\begin{DoxyItemize}
\item {\bfseries{Command \doxylink{classParser}{Parser}}}:\+ Understands verbs, subjects, and parameters.
\item {\bfseries{Pronoun Tracking}}:\+ Resolves referents contextually (e.\+g., {\ttfamily IT}, {\ttfamily HIM}, {\ttfamily HER}, {\ttfamily THEM}).
\item {\bfseries{Command History}}:\+ Supports {\ttfamily AGAIN} (repeat last command) and {\ttfamily OOPS} (correct a typo in the last command).
\item {\bfseries{Multi-\/\+Command Chaining}}:\+ Players can sequence commands using periods or semicolons (e.\+g., {\ttfamily TAKE LAMP. GO NORTH}).
\item {\bfseries{Disambiguation Prompts}}:\+ When the player\textquotesingle{}s target is ambiguous, the parser prompts for clarification before executing.
\end{DoxyItemize}\hypertarget{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md30}{}\doxysubsubsection{\texorpdfstring{Verb Dispatch System}{Verb Dispatch System}}\label{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md30}

\begin{DoxyItemize}
\item {\bfseries{Verb Registry}}:\+ The engine utilizes a massive Part 3 Verb Dispatch Refactor. The {\ttfamily verb\+Registry} efficiently maps input strings to game actions.
\item {\bfseries{Dynamic Capabilities}}:\+ Items and entities define what actions they support using {\ttfamily supports(name)} and {\ttfamily supports(name, func)}. This encapsulates logic within the object itself rather than a monolithic parser.
\end{DoxyItemize}\hypertarget{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md31}{}\doxysubsubsection{\texorpdfstring{Core Systems \& World Mechanics}{Core Systems \& World Mechanics}}\label{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md31}

\begin{DoxyItemize}
\item {\bfseries{State Management}}:\+ Tracks generic flags, rooms, items, NPCs, transitions, and inventories ({\ttfamily Game.\+h}).
\item {\bfseries{Environmental Mechanics}}:\+
\begin{DoxyItemize}
\item {\bfseries{Darkness \& Lighting}}:\+ Rooms and items manage illumination states via {\ttfamily is\+Dark}, {\ttfamily is\+Light\+Source}, and {\ttfamily is\+Lit}.
\item {\bfseries{Supporter Surfaces}}:\+ Objects can be placed on top of other objects using the {\ttfamily PUT X ON Y} mechanics.
\end{DoxyItemize}
\item {\bfseries{Player Metrics}}:\+ The engine tracks the player\textquotesingle{}s {\bfseries{Score}} and {\bfseries{Moves}}, displaying them continuously in a customizable {\bfseries{Status Bar}}.
\end{DoxyItemize}\hypertarget{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md32}{}\doxysubsubsection{\texorpdfstring{Narrative \& Feedback}{Narrative \& Feedback}}\label{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md32}

\begin{DoxyItemize}
\item {\bfseries{Verbosity Modes}}:\+ The engine supports {\ttfamily VERBOSE}, {\ttfamily BRIEF}, and {\ttfamily SUPERBRIEF} room description modes.
\item {\bfseries{Narrator Response Variety}}:\+ Allows for custom responses instead of generic default fallbacks.
\end{DoxyItemize}\hypertarget{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md33}{}\doxysubsection{\texorpdfstring{The I/\+O Abstraction Layer}{The I/\+O Abstraction Layer}}\label{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md33}
To support both synchronous native terminal execution and asynchronous web execution (via Web\+Assembly), the engine uses the {\ttfamily \doxylink{classIOInterface}{IOInterface}}:\+
\begin{DoxyItemize}
\item {\bfseries{{\ttfamily Native\+IO.\+h}}}:\+ Blocking {\ttfamily std::\+cin} and {\ttfamily std::\+cout} for standard native builds.
\item {\bfseries{{\ttfamily Web\+IO.\+h}}}:\+ Asynchronous I/\+O tailored for Emscripten, capturing inputs without blocking the browser thread.
\end{DoxyItemize}\hypertarget{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md34}{}\doxysubsection{\texorpdfstring{How it Ties Together}{How it Ties Together}}\label{dir_c096f47a06acd9e2921ad3fc6ef3398b_autotoc_md34}
The engine exposes these tools so that the {\ttfamily game/\+} module can confidently define content. The engine\textquotesingle{}s core bootstrapping process involves:\+
\begin{DoxyEnumerate}
\item Instantiating the appropriate {\ttfamily \doxylink{classIOInterface}{IOInterface}}.
\item Providing that interface to the master {\ttfamily \doxylink{classGame}{Game}} state object.
\item Supplying the lifecycle hooks ({\ttfamily init()}, {\ttfamily tick()}, {\ttfamily is\+Finished()}) which the game\textquotesingle{}s executable loop drives. 
\end{DoxyEnumerate}
